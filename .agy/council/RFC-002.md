# RFC-002: Architecture & Security Consensus for Train Platform

**Sana:** 2026-10-05 12:35:00 | **Konsensus:** APPROVED_BY_COUNCIL

## 1. 📐 Bosh Arxitektor (System Architect) Taklifi
- **Pattern:** Modular Clean Architecture (Core, API, Services, Models, Schemas, Static/Templates).
- **Backend:** FastAPI (Python 3.10+ async), SQLAlchemy 2.0 ORM, Pydantic v2 schemas, SQLite/PostgreSQL.
- **Frontend:** Responsive Modern SPA / Dashboard (Vanilla JS + Tailwind CSS + Lucide Icons) — ortiqcha murakkab build step talab qilmaydi, darhol ishlaydi.
- **Ma'lumotlar oqimi:**
  1. `Company` → 2. `Simulation` (Masalan: "FinTech Kredit Tahlilchisi") → 3. `SimulationTask` (1-topshiriq: Kredit scoring jadvali) → 4. `Submission` (Talaba topshirig'i) → 5. `Certificate` (Kriptografik tasdiqlangan QR).

## 2. 🕵️ Xavfsizlik Auditori (Skeptik) Talablari va Yechimlari
- ✅ **IDOR / BOLA Himoyasi:** Barcha modellar UUIDv4 asosida bo'ladi. Har bir submission egasi faqat o'z resursiga kira oladi.
- ✅ **Fayl xavfsizligi:** `SafeFileValidator` — ruxsat etilgan MIME tiplari (`pdf`, `xlsx`, `docx`, `png`, `jpg`), maksimal hajm (10MB), fayl nomi sanitizatsiyasi (`uuid_filename.ext`).
- ✅ **Autentifikatsiya:** JWT Access token (15 daqiqa) + Refresh token, PBKDF2/Bcrypt parollar shifrlanishi.
- ✅ **Sertifikat Soxtalashtirilishiga Qarshi:** Har bir sertifikat `HMAC-SHA256` orqali imzolangan unikal verification hash va `/verify/{cert_uuid}` ochiq tekshiruv sahifasiga ega bo'ladi.
- ✅ **Prompt Injection & XSS:** HTML va matn kiritmalari `html.escape` qilinadi, API ga to'g'ridan-to'g'ri xom HTML yuborish taqiqlanadi.
